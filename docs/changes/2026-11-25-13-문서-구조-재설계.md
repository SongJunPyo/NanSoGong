# 13. 규칙 문서 구조 재설계 (AGENTS.md + docs/rules)

- 날짜: 2026-11-25
- 관련: AI 전환 방향(Spring Boot 업무 · 승인 + Python · LangGraph AI 작업), 진행 관리 GitHub Issue 전환

## 요청 · 배경

AGENTS.md 한 파일에 공통 규칙 · 백엔드 · 프론트 · AI · DB 계약 · 담당 · 일정이 섞여 490줄을 넘었다. 일정 · 담당 · 계획 문서는 금방 낡고, AI 규칙은 "LangGraph를 쓰지 않는다"로 남아 있어 현재 방향과 달랐다.

## 바꾼 것

| 파일 | 변경 내용 |
|---|---|
| `AGENTS.md` | 한 줄 요약 · 기준 문서(작업 영역 → 먼저 읽을 문서 표) · 작업 원칙 · 명명 규칙(Python 추가) · 환경 · 보안 · GitHub · 테스트 규칙(단위 / 흐름, 완료의 정의) · 문서 관리 규칙만 남김. 담당 · 일정 삭제 |
| `docs/rules/backend.md` · `frontend.md` | 기존 AGENTS 3장 · 4장 이동. Python 내부 API 경계 추가 |
| `docs/rules/ai.md` | 기존 5장을 Python · LangGraph 기준으로 갱신. 기능별 그래프 흐름, 상태 저장 · 재개, 인증 미정 사항 반영 |
| `docs/rules/domain.md` | 도메인 목록(담당 칸 제거) · 경계 · 메서드 계약(제공 도메인 기준) · 업무 규칙 · 현재 범위 밖 목록 |
| `docs/rules/db.md` | 기존 3-3 · 3-5의 표 · 타입 · Flyway · 칸 계약, `매장 분리` 절 |

| `README.md`, `frontend/src/features/README.md` | 담당 표 삭제, 규칙 문서 · Issue 링크 추가, 수요 예측 실행 방식 갱신 |
| `docs/pjt_source/store-agent-db-desc.md`, `유저_플로우_1.04.md` | 담당 칸 · 줄 삭제, `AGENTS.md 3-2` 참조를 `docs/rules/db.md#매장-분리` 링크로 변경 |

머지된 마이그레이션과 `store-agent-db.sql` 주석의 "AGENTS.md 3-2"는 고칠 수 없어서 그대로 둔다. [DB 규칙 매장 분리](../rules/db.md#매장-분리)에 그 뜻을 적었다.
