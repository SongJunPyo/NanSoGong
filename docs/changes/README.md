# 개발 환경 변경 기록

개발 환경 · 저장소 구조 · 설정을 **무엇을, 왜, 어떻게** 바꿨는지 남기는 곳입니다.
팀원이 `git pull` 뒤에 "왜 이게 바뀌었지?" 싶으면 여기부터 봅니다.

## 쓰는 규칙

- 환경 · 설정 · 구조를 바꾸는 PR 에는 기록 파일을 **한 개** 함께 올린다 (기능 개발 PR 은 쓰지 않아도 된다)
- 파일 이름: `연-월-일-순번-짧은-설명.md` (예: `2026-11-20-01-add-router.md`)
- 내용은 [`_template.md`](_template.md) 를 복사해서 채운다
- **팀원이 해야 할 일**(파일 삭제, 명령 실행 등)이 있으면 반드시 적는다. 이 칸이 비어 있지 않은 기록은 PR 설명과 팀 채팅에도 공유한다
- 이미 머지된 기록은 고치지 않는다. 내용이 바뀌면 새 기록을 쓰고 옛 기록을 링크한다
